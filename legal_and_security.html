Legal and Security

Legal

My website contains many images, so I made sure to try and use copyright-free images, but it was not always possible to do so. However, because this website will never actually be published, and this is being done for educational purposes, I can legally use some copyrighted material. This is because, in the UK copyright laws, there’s an exception that “allow[s] students and researchers to make limited copies of all types of copyright works for non-commercial research or private study” (GOV.UK, https://www.gov.uk/guidance/exceptions-to-copyright).

I have a form in my website's contact page and to conform with GDPR, I would need to make sure I am not storing any personal data from this form, such as people’s names and emails. The form would send the email directly from the website to my email, and none of the data would be stored, only being used to give a name to link to the message they write, and their email as a means to transmit it to me. Therefore, I am not breaking any GDPR laws using the form.

Security

As I mentioned above, no personal data is stored from the form element. This means my form should be completely secure and so there should be no issues relating to the sensitive information that users may type into it.

For every link in my website, I made sure to add the ' rel=”noopener noreferrer” ' attribute. This is because ‘noopener’ is “a security measure to prevent malicious links from gaining access to a user’s browser”, and noreferrer “protects [a] site’s information from being transferred to the website users are navigating to” (Elegant Themes, https://www.elegantthemes.com/blog/wordpress/rel-noopener-noreferrer-nofollow). Therefore, these attributes should make the website that much more secure.
