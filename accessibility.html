Accessibility

Accessibility Statement

When developing this website, I made sure to make the website as accessible as possible to anyone that wants to use it, by using good coding practices and tools. For one, I used the contrast checker to ensure that the colours were contrasting enough and so as readable as possible. This revealed a few issues which I then could fix. Similarly, when I used the WAVE Web Accessibility Evaluation Tool, it revealed some more issues that I otherwise wouldn’t have considered as issues, which as improved the accessibility of the website. Also, for every image I have used in the website, I made sure to add alternative text, which explains what the image represents, this allows screen readers to help people who can’t fully see the image, understand what it represents. Finally, my navigation menu is simple and intuitive, requiring no 'burger-style' dropdown or similar, all the options are presented. This hopefully means no one would have any issues navigating my page.

Although I can always do more to improve the accessibility of my website directly in my code, there are many pieces of software that can do a lot of the heavy lifting for me and the person requiring extra support. For example, screen readers can read out the contents of my page to the visually impaired, without me having to really make any changes to my source code. An example of a popular screen reader is NVDA, which is free to use and open source.
